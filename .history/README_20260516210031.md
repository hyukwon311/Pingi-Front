# 핑이 (Pingi)

> 발음으로 측정하는 나의 취도

술자리에서 참가자들의 발음을 녹음하고 분석하여 취한 정도를 1~5단계로 측정하는 모바일 웹앱입니다.
술 마시기 전 기준 발음을 녹음한 뒤, 주기적으로 같은 문장을 다시 녹음하여 발음 변화율로 취도를 판단합니다.

## 주요 기능

- **세션 생성/참가** — 6자리 초대 코드로 친구를 초대하고 함께 참여
- **기준 발음 측정** — 주어진 문장을 녹음하여 기준선 설정
- **자동 발음 테스트** — 30분 간격으로 발음 테스트 알림, 수동 테스트도 가능
- **실시간 취도 대시보드** — 참가자별 취도 레벨(1~5단계) 및 음주량 확인
- **결과 리포트** — MVP 선정(술잔 왕, 철벽 간), 발음 변화율 그래프, 결과 공유

## 시작하기

### 사전 요구사항

- Node.js 18 이상
- npm 9 이상

### 설치 및 실행

```bash
git clone https://github.com/<your-username>/pingi-front.git
cd pingi-front
npm install
npm run dev
```

개발 서버가 `http://localhost:5173`에서 실행됩니다.

### 환경변수

프로젝트 루트에 `.env` 파일을 생성하여 백엔드 API 주소를 설정합니다.

```
VITE_API_URL=http://localhost:8080/api
```

설정하지 않으면 기본값 `http://localhost:8080/api`가 사용됩니다.

## 빌드 및 배포

### 프로덕션 빌드

```bash
npm run build
```

`dist/` 디렉토리에 정적 파일이 생성됩니다.

### 빌드 미리보기

```bash
npm run preview
```

### 배포 시 주의사항

SPA(Single Page Application)이므로 모든 경로 요청을 `index.html`로 리다이렉트하도록 서버를 설정해야 합니다.

**Vercel** — 별도 설정 없이 자동 지원

**Netlify** — `public/_redirects` 파일 추가:

```
/*    /index.html   200
```

**Nginx** — `try_files` 설정:

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

## 프로젝트 구조

```
src/
├── pages/          # 페이지 컴포넌트 (Splash, Login, Home, Session 등)
├── components/
│   ├── common/     # 공통 UI (Button, Card, Modal, Badge 등)
│   ├── home/       # 홈 화면 전용 컴포넌트
│   ├── layout/     # 레이아웃 (AppLayout, BottomTabBar, Header)
│   ├── session/    # 세션 관련 (ParticipantCard, DrunkLevelBadge 등)
│   └── voice/      # 음성 녹음 UI (RecordButton, VoiceWaveform)
├── services/       # API 클라이언트 (fetch 래퍼)
├── hooks/          # 커스텀 훅 (useSession, useVoiceRecorder 등)
├── contexts/       # React Context (Auth, Session)
├── types/          # TypeScript 타입 정의
├── constants/      # 상수 (라우트 경로, 취도 레벨, 잰말 문장)
└── utils/          # 유틸리티 함수
```
